# E-book: dezenas de plantas

[Painel](../PAINEL.md) · PDF com dezenas de plantas originais, para quem vai construir no Brasil.

## Estrutura

Capa → como escolher a planta pelo terreno → como ler uma planta → os 7 erros do vídeo → índice → **uma página dupla por planta** (planta humanizada, blueprint, 2 perspectivas, ficha e QR code da animação) → recuos e próximos passos.
