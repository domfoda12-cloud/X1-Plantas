# X1-Plantas

Materiais para vender plantas de casas no Brasil: anúncios, conteúdo gratuito, funil de WhatsApp e produção de vídeo 3D.

> Os textos são rascunhos. Os trechos entre [colchetes] precisam de dados reais antes de publicar.

## Arquivos

| Arquivo | Para que serve |
|---|---|
| `catalogo-plantas.md` | Resumo das plantas, medidas, público e preço |
| `anuncio-facebook.md` | Três variações de anúncio para o Facebook |
| `material-enviado.md` | Conteúdo gratuito enviado após o cadastro |
| `sequencia-whatsapp.md` | Mensagens de acompanhamento, dia a dia |
| `respostas-objecoes.md` | Respostas para as objeções mais comuns |
| `faq-compradores.md` | Perguntas frequentes sobre plantas, compra e construção |
| `brief-criativo.md` | Roteiro e estilo dos vídeos de anúncio |
| `roteiro-3d-cenas.md` | Lista de cenas para o vídeo 3D da primeira planta |
| `animacao-3d-e-plantas.md` | Conceitos de planta e fluxo de animação 3D |
| `instagram-plano.md` | Identidade, pilares e primeiros posts do perfil |
| `checklist-revisao-anuncio.md` | Revisão antes de publicar qualquer anúncio |
| `video/guia-editor.md` | Guia do vídeo "8 erros na planta": referência, roteiro de fala e edição |
| `video/saida/` | Vídeo pronto: rascunho e camada transparente para o editor |

## Antes de publicar

1. Preencha os campos entre colchetes.
2. Confirme as medidas e os preços com o arquiteto.
3. Passe pelo `checklist-revisao-anuncio.md`.
